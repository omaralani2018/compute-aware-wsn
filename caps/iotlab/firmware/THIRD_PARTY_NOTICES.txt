Third-party components of the flash images in caps/iotlab/firmware/, caps/iotlab/fixed/firmware/ and
caps/iotlab/radio/firmware/ (version 1.6)

The images were built from the application code of this package (caps/iotlab/app/, caps/iotlab/fixed/app_q/,
caps/iotlab/radio/; MIT, see LICENSE at the root) with the following components, whose terms apply to their parts:

- RIOT, tag 2025.07 (commit eb65305cf9f1b7affb50b17af5c12341b83a8636), https://github.com/RIOT-OS/RIOT, GNU Lesser
  General Public License version 2.1, https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html. The source of RIOT is
  public at that commit and the source of the application is in this package, so the images can be rebuilt and
  relinked with the commands of caps/README.md.
- Arm CMSIS (ARM-software/CMSIS_5, fetched by RIOT into its build folder), Apache License 2.0,
  http://www.apache.org/licenses/LICENSE-2.0 (M3 and nRF52840 images).
- STMicroelectronics cmsis_device_f1 (fetched by RIOT into its build folder), Apache License 2.0 (M3 images).
- Nordic Semiconductor device headers shipped with RIOT (cpu/nrf52/include/vendor), whose notice follows
  (nRF52840 images).
- newlib (Ubuntu 24.04 package libnewlib-arm-none-eabi 4.4.0), BSD-style licences listed in its COPYING.NEWLIB.
